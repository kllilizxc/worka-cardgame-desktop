# CardGame 执行台资料

执行任务需要项目事实时，先识别对象 ID 与需要的版本，再从知识库、卡牌库、资源库或功能进展的公开查询按需读取。文件正文以源文件为准，记录使用的版本。不要整库复制进任务上下文；资料变化不自动启动执行，也不自动修改正式项目。

涉及代码修改时，先从适用项目的知识库读取开发工作流，核对起始 ref，记录实际提交和规则版本。续做应读取该任务已有基线，不默认继承本地 HEAD 或其他任务的分支。卡牌定义以项目现有 JSON 为准，按卡牌 ID 查询、校验并保留原 ID。资源按 ID 和明确版本查询；使用关系从知识库反向链接核对，采用资源新版不自动替换使用位置。

只有项目确有改动或发布交付时才维护功能进展；纯诊断不登记。先按目标、项目、分支和 PR 查找已有记录，读取目标进展便笺实际使用的插件指南，再按其公开能力更新原记录。个人版与官方版的记录不能互相代替。
