# CardGame 桌面后台

本目录保留 CardGame 内容、资源、生产、候选采用、对局分析和预览的原有业务实现。`plugin.ts` 使用 Worka 公开宿主接口注册；`project-binding.ts` 管理用户为当前桌面选择的项目和服务生命周期。

构建只把声明的运行文件打包到桌面制品。宿主接口及 sharp、music-metadata 是共享 peer，不在包内复制原生二进制。`dist/plugin.js` 是本目录源码的编译结果；修改后运行 `bun run build`，不要单独修改生成清单。

项目服务按桌面和项目根目录隔离。未配置时只有安全的配置状态，既不猜测项目路径，也不读宿主历史配置。目录切换排空已接收请求、释放订阅、关闭原有服务并停止该桌面预览；绑定保存失败会恢复配置投影，旧绑定仍然有效。

当前实现来源于维护者提供的实际本机 CardGame 扩展源码，迁入本仓库后移除了旧宿主项目配置文件和部署路径约定。游戏项目保持独立。

项目绑定使用落盘的 opaque generation，不以路径字符串作为身份。旧绑定首次原地升级只迁移一次，写入失败不开放事件。目录切换更换 generation，旧编辑与旧回执失败关闭；原地升级的无代次轮次仅允许核对原执行任务，不重放未知副作用。

生产事件只携带冻结轮次身份，服务统一准备去重键，关系脚本从 canonical 查询读取交办快照。state、数据库与 events 仍是独立持久步骤；丢失绑定或候选回执沿用原操作重试。资源候选必须有本轮输出目录内真实文件及资源服务回执，迟到结果与派发回执保留历史而不回退当前轮次。

卡面布局和操作名从 note-4 的单一源码编译。中文 PNG 仍依赖运行环境的可用字体或宿主提供的字体路径，沿用已有系统字体查找；缺失时可能出现缺字或外观差异，本轮未消除这项环境依赖。当前 Linux / sharp 0.35.4 渲染已测，未做跨操作系统验收。
