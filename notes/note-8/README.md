# CardGame 内容库

这张便笺使用 `config.projectId` 连接 CardGame 内容后端，`config.mode` 选择知识库、卡牌库或资源库。文档、卡牌和资源正文始终从 `extension.cardgame-content.query` 查询；便笺状态只保存搜索、视图、筛选和收藏引用。

知识库以 Markdown 内部链接组织目录，保留 Markdown 阅读与源码编辑、真实图片预览、反向链接、局部关系图和移动/重命名影响预览。当前不提供搜索或文件树界面。卡牌库提供表格、卡面网格、三张以内比较及带版本校验的原始 JSON 保存。资源库按页查询当前版本，详情中按需加载缩略图、原图、音频波形和 spritesheet 预览，历史版本默认折叠。

知识库延续原有“资料入口＋正文”两栏阅读器，默认打开第一个入口。侧边栏登记资料的 `index.md`，具体目录写在索引正文中，通过普通相对链接导航；资料缺少目录时补写索引，不另做目录树。项目文档的编辑入口在正文工具栏，引用、关系及移动操作收在文件菜单中。保留返回／前进、本机重新读取和 Mermaid 图表。后端检索能力保留供其他工具使用，知识库搜索交互留待重新设计。

`config.resources` 继续保存升级前登记的设计规范和记忆等本机资料；这些入口通过 `extension.reference.file` 读取，兼容原来的 `queries.document({resourcePath, path?, from?})` 形状。项目内入口转到同一内容索引，支持 Markdown 编辑及版本检查。
